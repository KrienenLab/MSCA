## Marmoset SubCortical Cell Atlas (MSCA)

Code associated with our manuscript:

Dan, S., Turner, M.A., DeBerardine, M.,..., Long, B., and Krienen, F.M. (2026). Spatial and regulatory organization of cell identity across the primate subcortex.

#### Abstract

Mammalian brain cell identity is shaped by intrinsic factors and external context. We present a spatially resolved transcriptomic and gene regulatory atlas of cell types across all subcortical regions in a primate, the common marmoset. Dense sampling and cross-species integration revealed spatially precise neuronal assemblies, including ones in complex midbrain and diencephalic structures. Chromatin accessibility and transcriptional identity are spatially tuned within and across subcortical structures; spatial gradients within hippocampal subfields are orchestrated by graded transcription factors acting through graded enhancers. The primate-expanded thalamic γ-aminobutyric acid (GABAergic) population shares transcriptional and regulatory syntax with conserved midbrain populations, reflecting an evolutionary adaptation compared with rodents. Similar regional expression across cell types can arise by distinct regulatory architectures, as observed in telencephalic astrocytes and neurons. Conversely, distant cell types can share regulatory programs despite divergent identities: striatal GABAergic spiny projection neurons and telencephalic glutamatergic neurons share a postsynaptic regulatory program despite divergent lineages, regions, and neurotransmitter identities.

#### Use of AI in preparing this repository

The analysis code in the directories below was written and run by the authors. At the time of publication, an AI
model (Claude Fable 5.2, Anthropic, used through Claude Code) helped prepare these directories for release:

- `2_Taxonomy/Multiome_Spatial_Mapping/Spatial_Panel_Evaluation`
- `3_Analysis/ATAC_Regulon_Analysis`
- `3_Analysis/ATAC_Regional_Analysis`
- `3_Analysis/Nonneuron/Fig4_Astrocyte/Fig4D_F_MOXD1_regulons`

Its work was limited to organizing the files, writing the README files that map figure panels to code, removing
commented-out and unused sections from the notebooks, and checking statements in the manuscript against the
code and its outputs. It did not write or change the code that produced the results; the code that remains in
each notebook was checked to match the code as run.
